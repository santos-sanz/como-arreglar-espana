## Reproducibilidad y mantenimiento

1. Conservar periodo observado, fecha de publicación y fecha de consulta separados.
2. Actualizar primero dato y definición, después texto y visualización; nunca cambiar solo el número grande.
3. Para comparaciones, exigir misma unidad, población, geografía, periodo y metodología.
4. Para causalidad, describir intervención, comparación, horizonte y límites de extrapolación.
5. Para propuestas, declarar responsable, coste, afectados, métrica y criterio de revisión.
6. Registrar nuevos errores en la auditoría y mantener el original como archivo histórico, no como lectura vigente.

No se redistribuyen informes completos de terceros. Los enlaces permiten inspeccionar las publicaciones originales. El proyecto no reclama cobertura exhaustiva de toda la evidencia disponible.
